# 🎬 Movie Ranking Analysis (Python Project)

## 📌 Overview  
Collaborated on a Python-based data analysis project to explore movie trends and build models to predict movie success using real-world datasets through Kaggle.

---

## 🚀 Key Highlights  

- 📊 Analyzed **2 movie datasets** (Top Movies + Rotten Tomatoes) to identify trends and correlations  
- 🧹 Cleaned and transformed data, including handling missing values and converting financial data to USD  
- 📈 Performed **exploratory data analysis (EDA)** to uncover patterns in genre, ratings, revenue, and release trends  
- 💰 Engineered features such as **ROI (Return on Investment)** to better measure movie performance  
- 🤖 Built and evaluated multiple machine learning models:  
  - Decision Tree  
  - Random Forest  
  - Logistic Regression  
  - Naive Bayes  
- ⚖️ Addressed **imbalanced data** and improved model performance through feature selection and engineering  
- 🔍 Used metrics such as **accuracy, precision, recall, and confusion matrix** to evaluate models  

---

## 🛠️ Tools  
`Python` • `Pandas` • `NumPy` • `Matplotlib` • `Scikit-learn`  

---

## 📊 Key Insights  
- High budget is strongly correlated with higher income, but not necessarily higher ROI  
- Movie ratings and revenue show only a weak relationship  
- Genre, release timing, and runtime influence success more than a single factor  
- Director reputation alone is not a strong predictor of success  
- Movie success is influenced by **multiple combined factors, not one variable**
